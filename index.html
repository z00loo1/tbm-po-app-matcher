Purchase Order → Application Matching

Use PO titles, descriptions, vendor names and verified App IDs to discover likely application mappings in APM. Review the evidence before accepting a recommendation.

How to interpret results: The score is a heuristic match-strength score (0–100), not a probability. Existing valid App IDs stay unchanged. Missing IDs are never automatically assigned: approving a recommendation only updates this local review session and export.
